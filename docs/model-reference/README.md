# 二层养殖工厂模型依据

原始资料为《渔机所汇报0406》。此目录只保留建模所需的原始参考图，没有修改源 PPT。

- `three-stage-plan.jpeg`：第 14 页三段式养殖系统工艺图。沿用池列位置与水处理位于池列端部的拓扑；演示页面按需求展示 4 个虾苗池、8 个养殖池、8 个大池。
- `feed-layout.png`：第 24 页输料布置。用于顶部输料总管、立柱、池位分料支路和投饲桶的构造。
- `site-aisle.jpeg`、`site-support.jpeg`：第 18 页现场照片。用于黑色池壁、蓝色管架、阶梯式钢支撑和黄色检修格栅的构造。

## 尺度与设计值

第 14 页提供池径 1.5 / 2.5 / 4 m，以及分段处理量 30 / 30 / 60 m³/h；第 17 页提供幼虾、过渡虾、成虾设计密度 6000 / 1700 / 640 尾/m³，检修通道不小于 0.70 m。模型用米作为单位，格栅通道宽 0.72 m。

原图没有足够清晰的池壁、水深和支撑高度标注，模型中的水深 0.85 / 1.05 / 1.20 m、池底标高 2.10 / 1.30 / 0.22 m，以及厂房截取范围 23 × 29 m 是展示用推定值，不是竣工测绘尺寸。池间净距为敷设管线和转运槽做了小幅增加；虾苗池数量按演示需求调整为 4 个。页面池位参数明确标为设计密度，不代表实时监测值。

## 连接与模型细节

每个阶段独立连接：池底排水 → 微滤/蛋白分离组合 → 生化池 → UV → 循环泵 → 供水总管 → 池侧进水。曝气和投喂分别连接至本阶段鼓风机与料仓；传感器经本地控制盒接入顶部线槽和联动柜。一级与二级池有挡板开口，各接至下一级池的独立坡槽。池底可见充气膜，用于说明原有 RAS 转池机构，未增加自动触发的生产控制功能。

凡纳滨对虾几何沿用 RAS 项目的解剖结构：头胸甲、六节腹部、额剑、触须、眼柄、五对步足及尾扇。使用共享几何和实例渲染，按实际体长缩放，少量抽样展示；可见虾的数量不等于设计存塘量。

## Svelte 页面与模型代码

- `/sites/hainan/entry`：总览中央展示综合体全景模型（地上 10 层、地下 B1），保留周围业务模块。
- `/sites/hainan`：展示二层设施模型，模型池位选择与下方演示监控联动。
- `src/lib/components/FacilityModel.svelte`：透明外壳与全宽深色模型画布，提供低/高精度选择、加载进度、旋转、缩放、重置与楼层/池位信息提示。
- `src/lib/three/facility-model.ts`：从甲方 HTML 样例迁移的 Three.js 场景、模型、动画与交互；依赖项目安装的 `three` 包，不加载样例 HTML。
- `src/lib/three/progressive/`：Worker 低/高精度模型生成、静态几何合批与缓冲传输、主线程分片解包、模型缓存及资源释放。先显示低精度，空闲时准备高精度；由用户手动切换。低精度降低几何分段、材质复杂度和虾实例数。
- 页面切到后台会暂停高精度准备；低端/触控设备维持低像素比和保守帧率。
- 加载方式迁移不复制甲方样板文件；当前仓库不保留 `4.html`。
- 原根目录和 `static/` 下的 `4.html` 已移除。页面及业务区块按职责拆分为 Svelte 子组件，所有 `.svelte` 文件保持在 300 行以内。
